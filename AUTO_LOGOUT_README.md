# Автоматический выход в 22:00 - Документация

## Описание проблемы
Ранее система выполняла автоматический выход в 22:00, но после этого не позволяла пользователю войти обратно, так как сразу же снова выполняла выход.

## Решение
Теперь система работает следующим образом:

### Логика работы
1. **Автоматический выход происходит только один раз в день** - в 22:00 по московскому времени
2. **После выхода пользователь может снова войти** в систему в любое время
3. **Следующий автоматический выход** произойдет только на следующий день в 22:00
4. **В полночь система сбрасывает** флаг автоматического выхода для подготовки к следующему дню

### Технические детали
- Проверка времени происходит каждые 5 минут (вместо 30 минут для более точного срабатывания)
- Дата последнего автоматического выхода сохраняется в `localStorage` с ключом `lastAutoLogoutDate`
- Система использует московское время (`Europe/Moscow`)
- Автоматический выход происходит только в 22:00 (не позже)

## Тестирование

### Автоматическое тестирование
В консоли браузера можно использовать следующие функции:

```javascript
// Импортируем тестовые функции
import { 
  testAutoLogoutLogic, 
  simulateAutoLogout, 
  clearAutoLogoutRecord, 
  getAutoLogoutStatus 
} from './src/utils/testAutoLogout';

// Проверить текущую логику
testAutoLogoutLogic();

// Получить статус автовыхода
getAutoLogoutStatus();

// Симулировать автовыход (для тестирования)
simulateAutoLogout();

// Очистить запись о последнем автовыходе
clearAutoLogoutRecord();
```

### Ручное тестирование

#### Тест 1: Проверка автоматического выхода в 22:00
1. Войдите в систему до 22:00
2. Дождитесь 22:00
3. Система должна автоматически выполнить выход
4. Попробуйте войти снова - вход должен быть успешным

#### Тест 2: Проверка однократности автовыхода
1. Войдите в систему после того, как уже был выполнен автовыход сегодня
2. Система НЕ должна выполнять повторный автовыход
3. Пользователь должен оставаться в системе

#### Тест 3: Проверка сброса в полночь
1. После полуночи система должна очистить запись о последнем автовыходе
2. На следующий день автовыход снова должен работать в 22:00

### Логирование
Система выводит подробные логи в консоль браузера:
- Время проверки и текущий статус
- Информацию о том, был ли уже выполнен автовыход сегодня
- Уведомления о выполнении автовыхода
- Уведомления об очистке записи в полночь

## Возможные проблемы и решения

### Проблема: Автовыход не срабатывает
**Решение:** Проверьте консоль браузера на наличие ошибок и убедитесь, что пользователь авторизован.

### Проблема: Автовыход срабатывает несколько раз
**Решение:** Очистите localStorage и перезагрузите страницу.

### Проблема: Время определяется неправильно
**Решение:** Проверьте настройки часового пояса в системе.

## Команды для очистки (в консоли браузера)
```javascript
// Очистить запись о последнем автовыходе
localStorage.removeItem('lastAutoLogoutDate');

// Посмотреть текущую запись
console.log(localStorage.getItem('lastAutoLogoutDate'));
```
