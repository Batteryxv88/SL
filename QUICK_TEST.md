# Быстрое тестирование автоматического выхода

## Для немедленного тестирования

### 1. Откройте консоль браузера (F12)

### 2. Проверьте текущий статус:
```javascript
// Посмотреть, была ли уже запись о сегодняшнем автовыходе
console.log('Последний автовыход:', localStorage.getItem('lastAutoLogoutDate'));
console.log('Сегодня:', new Date().toDateString());
```

### 3. Симулируйте автовыход (чтобы проверить, что система не будет выходить повторно):
```javascript
// Установить запись о том, что автовыход уже был сегодня
localStorage.setItem('lastAutoLogoutDate', new Date().toDateString());
console.log('Автовыход симулирован для сегодня');
```

### 4. Очистите запись (чтобы система снова могла выполнить автовыход):
```javascript
localStorage.removeItem('lastAutoLogoutDate');
console.log('Запись очищена, автовыход снова возможен');
```

### 5. Проверьте логи в консоли
Система каждые 5 минут выводит информацию о проверке времени:
```
Проверка времени: 15:30 МСК, дата: Wed May 29 2024, последний автовыход: null
```

## Что изменилось

✅ **БЫЛО:** Система выходила каждый раз при входе после 22:00  
✅ **СТАЛО:** Система выходит только один раз в 22:00, после чего можно входить свободно

✅ **БЫЛО:** Проверка каждые 30 минут  
✅ **СТАЛО:** Проверка каждые 5 минут (более точно)

✅ **ДОБАВЛЕНО:** Автоматическая очистка записи в полночь для следующего дня

## Проверка работы

1. **До 22:00:** Войдите в систему - все работает нормально
2. **В 22:00:** Система автоматически выполнит выход
3. **После 22:00:** Войдите снова - вход должен быть успешным, повторного выхода не будет
4. **На следующий день:** В 22:00 снова произойдет автоматический выход
